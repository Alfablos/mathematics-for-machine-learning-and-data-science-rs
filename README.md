# Mathematics for Machine Learning and Data Science in Rust

This repo attempts to find the rust tools equivalent to python ones used for accomplishing mathematical tasks in ML and Data Science.


## Sources

* [[Coursera] Deeplearning.AI - Mathematics for Machine Learning and Data Science specialization](https://www.coursera.org/specializations/mathematics-for-machine-learning-and-data-science)
* [ndarray (0.16.1)](https://docs.rs/ndarray/latest/ndarray/)
* [ndarray-linalg](https://docs.rs/ndarray-linalg/0.17.0)
* [linfa-linalg](https://docs.rs/linfa-linalg/latest/linfa_linalg/)


## Rust

* **01_linear_algebra/02_systems_of_linear_equations/rust** uses ndarray-linalg with the *openblas-static* feature, which compiles OpenBLAS and statically links it.
